# Johnny Li

A minimalist, high-performance personal website.

## Overview
This is a lightweight, single-page portfolio built with pure HTML and CSS. It features a clean, modern aesthetic with automatic light/dark mode support and zero JavaScript dependencies.

## Features
- 🎨 **Automatic Dark Mode:** Seamlessly adapts to system preferences.
- 📱 **Fully Responsive:** Optimized for mobile, tablet, and desktop.
- ⚡ **Highly Optimized:** Minimal CSS, no frameworks, no JavaScript.
- ♿ **Accessible:** Semantic HTML, proper contrast, and focus states.

## Tech Stack
- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- [Inter](https://fonts.google.com/specimen/Inter) (via Google Fonts)

## Deployment
This site is designed to be hosted on [GitHub Pages](https://pages.github.com/). 

1. Push the `index.html` file to your repository's `main` branch.
2. Go to your repository **Settings** > **Pages**.
3. Under "Source", select the `main` branch and click **Save**.
4. Your site will be live at `https://<your-username>.github.io/<repository-name>/`.
